# ClassSync

A Learning Management System (LMS) built with React, Flask, PostgreSQL, and Supabase.

## Features

- Authentication & Authorization
- Subject Management
- Folder Management
- File Uploads
- Announcements
- Assignments
- Comments
- Activity Tracking

## Tech Stack

Frontend:
- React
- Vite

Backend:
- Flask
- JWT

Database:
- Supabase PostgreSQL

Deployment:
- Vercel
- Render
